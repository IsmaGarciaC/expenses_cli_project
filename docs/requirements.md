# Requerimientos y Alcance de Proyecto

Este proyecto tiene como objetivo crear una Command Line Interface (CLI) que ayude al usuario a llevar registro de sus gastos de forma eficiente. Sin depender de hojas de cálculo, fórmulas complejas o de hacer cada operación manualmente. 

## Problema
En el día a día existen gastos que se deben registrar. Muchas plataformas ofrecen interfaces completas, pero a su vez complejas para quienes quieren empezar o simplemente no necesitan tantos detalles para su día a día.  
  
Quienes prefieren usar hojas de calculo, consideran que es una tarea manual repetitiva que solo les quita tiempo. Además usar fórmulas complejas para listar o filtrar datos puede elevar la complejidad.

## Solución Propuesta
Una herramienta de terminal que almacene los movimientos localmente y permita consultarlos posteriormente.

## Usuario Objetivo
Todos los usuarios que deseen registrar sus gastos de forma intuitiva y fácil desde su terminal, es decir que tenga una noción básica de comandos para usar en su computadora.

## Que esperar (MVP)
- Una aplicacion desplegada como CLI
- Funcionalidad de registrar gastos
- Funcionalidad de listar gastos
- Funcionalidad de eliminar gastos
- Guardar los datos en formato JSON
- Calcular el total de los gastos
- Consultar gastos por ID

## Que no esperar
- Filtrar Gastos por categoría
- Presupuestos mensuales
- Cuentas de usuario
- Interfaz gráfica
